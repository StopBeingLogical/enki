THE FOUR MAJOR IMPROVEMENTS
================================================================================

IMPROVEMENT 1: Semantic Evaluation
  Problem:  Count tasks (gameable)
  Solution: LLM-as-a-judge grades semantic quality (1-5)
  Impact:   Catches useless micro-tasks; Router trusts quality

IMPROVEMENT 2: Decoupled Pipeline
  Problem:  JSON formatting error → crash → lose Stage 3 data
  Solution: Auto-repair JSON; continue pipeline even if formatting is bad
  Impact:   Models aren't discarded for minor issues

IMPROVEMENT 3: Resilient Infrastructure
  Problem:  Hardcoded 5-min timeout fails on slow hardware
  Solution: Configurable timeout, explicit token limits, temp tuning
  Impact:   Fair comparison across hardware; infrastructure ≠ capability

IMPROVEMENT 4: Scaffolding Discovery (Crown Jewel)
  Problem:  Model fails zero-shot → marked unsuitable forever
  Solution: Auto-retry with few-shot examples, CoT, explicit schema
  Impact:   Discover what each model needs; Router prepends context

================================================================================
KEY DESIGN DECISIONS (Built Into v2.0)
================================================================================

DECISION 1: v2.0 is 100% backward compatible with v1.0
  Implementation: All v2.0 features are optional (flags/params)
  v1.0 users can upgrade with zero config changes

DECISION 2: Evaluator model is optional
  Implementation: --evaluator-model (default: None)
  If not provided: use v1.0 composite algorithm

DECISION 3: Scaffolding is automatic, not manual
  Implementation: If level 0 fails, try level 1; if 1 fails, try 2
  Result: Models are auto-profiled; Router gets exact requirements

DECISION 4: Semantic score floors granularity score
  Implementation: Composite = (gran*0.3) + (sem*0.4) + (self*0.3)
  Result: Can't game metrics with useless micro-tasks

================================================================================
SUCCESS CRITERIA FOR v2.0
================================================================================

Methodological:
  ✓ Semantic evaluator prevents metric gamification
  ✓ Evaluator prevents weak models from scoring higher than capable ones
  ✓ Evaluator judgments are sensible and explainable

Pipeline Resilience:
  ✓ JSON formatting errors don't crash pipeline
  ✓ Stage 3 runs even if Stage 2 formatting is imperfect
  ✓ Context window exhaustion is detected separately from capability failure
  ✓ Timeouts are configurable without false negatives

Scaffolding Discovery:
  ✓ Models retry with Level 1 (few-shot) if zero-shot fails
  ✓ Models retry with Level 2 (CoT) if Level 1 fails
  ✓ Registry shows scaffolding level needed (0, 1, or 2)
  ✓ Router can prepend context based on level

Backward Compatibility:
  ✓ v1.0 users can upgrade with zero config
  ✓ Running with --max-scaffolding-level 0 = v1.0 behavior
  ✓ Running without --evaluator-model = v1.0 scoring
